# Source-data notice and correction process

`data/rezona/games.enriched.json` is a factual archive of API responses collected
from Rezona endpoints during the documented collection run. It preserves the detail
object returned by the source API together with collection tags and provenance.

The MIT license covers this repository's original code, documentation, diagrams, and
generated header art. It does not grant rights in Rezona-sourced game content,
creator-provided material, trademarks, or other third-party content referenced by the
dataset.

If you are a rights holder or otherwise believe a record is inaccurate, sensitive, or
should not be distributed, please open a GitHub issue with the relevant game ID and
supporting context. If your request should not be public, use the contact method on
the maintainer's GitHub profile instead. Requests will be reviewed promptly and
supported corrections or removals will be made in a follow-up revision.
